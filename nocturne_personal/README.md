# Nocturne Personal Release

Independent Personal fork on the tested Daily base. Default host port 8450, separate data and cookies.

Personal 0.2.12 adds Google Health under Settings -> Connectors & Apps -> Server Connectors, with an inventory preview and selected imports into Nocturne's step, heart-rate, weight and sleep histories from a chosen date. The year overview has four average-glucose color boundaries and two bounds for the other supported metrics. Color settings do not change glucose targets or Time in Range calculations. Google requires your own OAuth client and consent; real account access must still be tested. No dosing advice or insulin/IOB changes.
