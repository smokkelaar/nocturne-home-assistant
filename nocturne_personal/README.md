# Nocturne Personal Release

Independent Personal fork on the tested Daily base. Default host port 8450, separate data and cookies.

Personal 0.3.5 previews only the configurable Year Overview color ranges from nightscout/nocturne#1273. Non-glucose metrics have a remembered minimum and maximum focus range; average glucose keeps its clinical color model with four adjustable boundaries. This preview does not include the separate Google Health contribution. No dosing advice or insulin/IOB changes.

[Installation and updates](https://github.com/smokkelaar/nocturne-home-assistant/blob/main/docs/PERSONAL.md).
