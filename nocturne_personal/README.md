# Nocturne Personal Release

Independent Personal fork on the tested Daily base. Default host port 8450, separate data and cookies.

Personal 0.3.1 previews the cleaned Google Health connector under Settings -> Connectors & Apps -> Server Connectors. It uses the connector framework for configuration, secrets and sync health, and writes selected imports directly into Nocturne's step, heart-rate, weight and sleep histories. The temporary Google Health database schema has been removed. Google requires your own OAuth client and consent; real account access must still be tested. No dosing advice or insulin/IOB changes.

[Installation and updates](https://github.com/smokkelaar/nocturne-home-assistant/blob/main/docs/PERSONAL.md).
