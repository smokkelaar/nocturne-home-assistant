# Nocturne Personal Release

Independent Personal fork on the tested Daily base. Default host port 8450, separate data and cookies.

Personal 0.3.19 includes Google Health imports for steps, heart rate, weight and sleep. Progress refreshes while the connector page is open; the percentage estimates data-type stages, not remaining time. No dosing advice or insulin/IOB changes.

[Installation and updates](https://github.com/smokkelaar/nocturne-home-assistant/blob/main/docs/PERSONAL.md).
