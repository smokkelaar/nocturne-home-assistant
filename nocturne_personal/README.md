# Nocturne Personal Release

Independent Personal fork on the tested Daily base. Default host port 8450, separate data and cookies.

Personal 0.3.46 includes Google Health imports for steps, heart rate, weight and sleep. Progress refreshes while the connector page is open; the percentage estimates data-type stages, not remaining time. The reviewed documentation adds searchable page-specific help, visual reading aids, one shared glucose reference and direct settings links. Dashboard help now includes every widget with fictional data, complete selectable situations, one explanation at a time and an interactive chart that does not change your settings. The book opens independently navigable documentation; help scrolls while the background stays in place. Appearance controls layout, transparency and blur. Google Health setup has a step-by-step guide; imports support steps, heart rate, weight and sleep. No dosing advice or insulin/IOB changes.

[Installation and updates](https://github.com/smokkelaar/nocturne-home-assistant/blob/main/docs/PERSONAL.md).
